# q3-2026-maintenance-log

This repository holds the **Q3 2026 maintenance log** for the **release-ops rotation**.

## Purpose

Each quarter, the engineer on rotation for release-ops keeps the maintenance log here:
quarterly maintenance activities, decisions, and follow-ups, so the rest of the team
can pick up context at any time.

The working checklist for this quarter lives in [MAINTENANCE.md](MAINTENANCE.md).
